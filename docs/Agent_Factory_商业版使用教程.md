## 🛠️ 部署指南

### 你需要准备什么？

- 一台能上网的电脑（Windows / Mac / Linux 都可以）
- 一个 AI 模型的 API Key（后面会教你怎么获取）
- 基本操作能力（会解压文件、会打开终端）

### 第一步：解压交付包

你拿到的 ZIP 压缩包，解压到任意文件夹。

```
📁 挑战杯路演PPT润色助手_v1.0.zip
    ├── 📄 挑战杯路演PPT润色助手.py   ← 你的智能体（CLI版）
    ├── 📄 requirements.txt           ← 依赖清单
    ├── 📄 README.md                  ← 英文说明（可选）
    └── 📄 .env.example               ← API 配置模板
```

> 💡 **提示**：建议解压到一个名称不包含中文的路径，例如 `D:\agents` 或 `~/agents`。

### 第二步：安装依赖

打开你的**终端（Terminal）**：

**Windows 用户：**
```bash
# 进入你解压后的文件夹
cd D:\agents\挑战杯路演PPT润色助手

# 一键安装所有依赖
pip install -r requirements.txt
```

**Mac / Linux 用户：**
```bash
# 进入你解压后的文件夹
cd ~/agents/挑战杯路演PPT润色助手

# 一键安装所有依赖
pip3 install -r requirements.txt
```

> ⏳ 这个过程可能需要 1-2 分钟，取决于你的网速。
>
> ✅ 看到 `Successfully installed openai-1.x.x` 就说明安装成功了。

## 🔑 算力接入

你的智能体需要连接一个 AI 模型才能工作。这里教你如何配置。

### 获取 API Key

**如果你使用 DeepSeek（推荐）：**
1. 打开 https://platform.deepseek.com
2. 注册账号 → 登录
3. 进入「API Keys」页面
4. 点击「创建 API Key」，复制生成的密钥

**如果你使用其他模型：**

| 模型 | 注册地址 | 费用 |
|------|---------|------|
| 通义千问 Qwen | https://dashscope.aliyun.com | 新用户免费额度大 |
| 智谱 GLM | https://open.bigmodel.cn | 注册送体验金 |
| 百度千帆 | https://cloud.baidu.com | 按量付费 |

### 配置 .env 文件

1. 在解压后的文件夹中，找到 `.env.example` 文件
2. **复制一份**，重命名为 `.env`（注意文件名前面有个点）
3. 用记事本打开 `.env`，填入你的信息：

```bash
# 模型配置（支持任意 OpenAI 兼容 API）
MY_API_KEY=sk-your-api-key-here        ← 改成你的 API Key
MY_BASE_URL=https://api.deepseek.com/v1  ← 改成模型官方地址
MY_MODEL_NAME=deepseek-chat              ← 改成模型名称
```

**各种模型的具体填法：**

```bash
# ─── DeepSeek ───
MY_API_KEY=sk-你的key
MY_BASE_URL=https://api.deepseek.com/v1
MY_MODEL_NAME=deepseek-chat

# ─── 通义千问 Qwen ───
MY_API_KEY=sk-你的key
MY_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
MY_MODEL_NAME=qwen-turbo

# ─── 智谱 GLM ───
MY_API_KEY=你的key
MY_BASE_URL=https://open.bigmodel.cn/api/paas/v4
MY_MODEL_NAME=glm-4

# ─── 自定义中转 API ───
MY_API_KEY=你的key
MY_BASE_URL=你的中转地址
MY_MODEL_NAME=你购买的模型名
```

> 🛑 **重要**：`.env` 文件包含你的 API Key，**绝对不要**分享给任何人！也不要把 `.env` 上传到公开网络。

## ❓ 常见问题

**Q：运行报错 `ModuleNotFoundError: No module named 'openai'`？**
A：忘记安装依赖了。运行 `pip install -r requirements.txt`。

**Q：运行后没有输出任何内容？**
A：检查 `.env` 文件中的 API Key 和 Base URL 是否正确填写。

**Q：提示 `Authentication Error`？**
A：API Key 可能已过期或填错了。回到官网重新生成一个 Key。

**Q：输出结果质量不好？**
A：可以试试换成更强的模型（如 deepseek-chat → claude-3-sonnet），或者把你的需求写得更具体一些。

**Q：能不能在手机上运行？**
A：目前是 Python 程序，可以在手机上用 Termux 运行，但我们推荐在电脑上使用以获得最佳体验。
